
# Dashboard de Usuarios, Publicaciones y Comentarios

## Descripción
Aplicación interactiva desarrollada en Python y Streamlit que permite consultar, organizar y analizar información de usuarios, publicaciones y comentarios mediante las API públicas de JSONPlaceholder.

## Objetivo
Aplicar el proceso ETL para extraer, transformar y cargar datos, presentándolos mediante indicadores, gráficos y tablas interactivas.

## Tecnologías utilizadas
- Python
- Streamlit
- Pandas
- Requests
- Plotly
- OpenPyXL

## Fuentes de datos
- Usuarios: https://jsonplaceholder.typicode.com/users
- Publicaciones: https://jsonplaceholder.typicode.com/posts
- Comentarios: https://jsonplaceholder.typicode.com/comments

## Funcionalidades
- Indicadores KPI.
- Visualización de usuarios, publicaciones y comentarios.
- Gráficos de barras, circular y dispersión.
- Filtros interactivos.
- Ranking de usuarios.
- Tablas relacionadas y dinámicas.
- Exportación a Excel y CSV.
- Manejo de errores y caché de consultas.

## Instalación

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

## Ejecución

Iniciar la aplicación:

```bash
streamlit run app.py
```
